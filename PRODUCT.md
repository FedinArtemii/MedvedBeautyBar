## Platform

web

## Stack

Локальный WordPress с редактируемым контентом и статическая публикация на GitHub Pages из FedinArtemii/MedvedBeautyBar.

## Users

Девушки, которые выбирают студию красоты и хотят записаться через ВКонтакте.

## Product Purpose

Показать студию и дать прямой переход в её сообщество ВКонтакте для записи.

## Brand Commitments

Название Medved Beauty Bar. Логотип из брифа — источник фирменного розового и круглого мотива. Позиционирование из брифа — розовое пространство красоты и эстетики. Hairora служит референсом движения.
